AI Assistant 用户指南与最佳实践

一、支持的文档格式

平台支持多种常见文档格式自动解析，包括 PDF 文档、Word 文档、PPT 演示、图片文件、复杂排版 PDF 支持智能解析。上传后系统自动完成解析、分块和向量化。

二、智能检索机制

两阶段检索：系统采用两阶段混合检索策略。第一阶段通过向量相似度和关键词匹配进行粗筛召回，第二阶段使用专门的 reranker 模型对候选片段进行相关性重打分，保留最相关的结果。

HyDE 增强检索：当系统检测到首次检索结果置信度不足时，会自动触发 HyDE（假设性文档嵌入）策略，先生成一个假设性回答来辅助检索，从而提高召回率。

检索质量判断：如果检索结果质量较低（最高分低于阈值），系统会提示未找到足够相关信息并建议用户换一种方式提问。

三、多轮对话

系统支持多轮对话，保留最近 30 轮的对话历史。当对话轮次过多时，系统会自动对早期对话进行摘要压缩。

四、回答质量保障

每次查询返回的结果中会包含质量评估信息。检索质量维度评估检索结果的相关性评分，不通过时给出警告提示。安全合规维度评估回答内容是否符合安全策略，不通过时直接拦截并替换为安全提示。事实准确性维度评估回答是否忠于检索到的文档内容，不通过时降级处理，清空回答保留来源。回答相关性维度评估回答是否与用户问题相关，不通过时追加提示信息。

五、API 接口

POST /api/query 向知识库提问，返回完整回答与来源。POST /api/query/stream 流式查询，先返回来源信息再逐字返回回答。POST /api/upload 上传文档，支持 multipart/form-data 格式。

六、常见问题

问：平台支持哪些大语言模型？答：系统支持 DeepSeek、智谱 GLM-5.1 和 OpenAI 兼容接口，可根据配置自动路由。

问：嵌入模型的向量维度是多少？答：系统使用 1024 维的向量进行语义检索。

问：部署需要多少资源？答：最低需要 8GB 内存和 50GB 磁盘空间，Python 3.11+ 和 PostgreSQL 16+。

问：如何上传文档？答：可通过 Web 界面上传，或调用 POST /api/upload API 上传。

问：如何处理安全违规内容？答：采用关键词预筛加 LLM 语义评判的两级检测机制，检测到违规内容会直接拦截并返回安全提示。
