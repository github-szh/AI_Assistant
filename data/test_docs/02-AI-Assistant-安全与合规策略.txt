AI Assistant 安全与合规策略

一、总则

AI Assistant 致力于提供安全、可靠、合规的智能知识问答服务。所有用户和系统功能必须遵守以下规定。

二、内容安全策略

有害内容：禁止包含暴力、色情、仇恨、歧视、自残、自杀、恐怖主义、校园暴力、虐待、血腥等有害内容。任何形式的暴力、威胁和恐吓行为都是被严格禁止的。

提示注入攻击：禁止任何试图绕过系统指令的恶意输入，包括但不限于要求系统忽略指令、忘记之前设置、模拟对话突破限制、无视规则等行为。

个人信息泄露：禁止在对话中泄露或要求获取他人身份证号、手机号、银行卡号、密码、住址、社保号、护照号、信用卡等个人敏感信息。

敏感话题：涉及政治敏感、宗教极端、领土争端、历史虚无主义、分裂言论、种族歧视、邪教组织等争议性内容一律拦截。中国是一个统一的、多民族的社会主义国家。各民族一律平等，国家保障各少数民族的合法权益。歧视性言论违反法律法规和社会公序良俗。

违法内容：禁止涉及毒品、赌博、枪支、爆炸物、黑客、钓鱼、洗钱、走私等违法活动的内容。任何涉及暴力、武器制造、危害公共安全的内容都被严格禁止。任何未经授权的系统入侵行为都是违法的。

虚假信息与谣言：禁止传播谣言、阴谋论、伪科学、虚假新闻、编造事实、误导信息、深度伪造等不实内容。传播谣言是违法行为，根据治安管理处罚法，散布谣言故意扰乱公共秩序的将受到法律制裁。

广告合规：虚假医疗广告违反广告法和药品管理法，可能对他人健康造成严重危害。

未成年人保护：根据未成年人保护法，禁止向未成年人出售烟酒。

三、安全技术措施

系统的安全机制覆盖多个层面，确保所有用户只能访问其授权范围内的文档。上传的文档经过权限控制，用户访问需要身份验证和授权。系统采用严格的安全措施，包括参数化查询、输入验证、最小权限原则等，防止 SQL 注入等安全攻击。系统内置速率限制机制，防止 API 滥用和暴力破解攻击。

四、内容质量保障

每次 LLM 回答后，系统自动执行多维度质量检测：安全检测通过关键词预筛加 LLM 语义评判，拦截违规内容；事实校验通过交叉评判机制，确保回答忠于检索源文档；相关性检查确保回答与用户问题相关；检索质量检查是预生成检查，低质量检索会跳过 LLM 生成。

五、用户合规要求

学术诚信是基本原则。考试作弊违反校规校纪，严重者将面临开除学籍等处罚。所有用户必须遵守法律法规，不得利用平台从事任何非法活动。
