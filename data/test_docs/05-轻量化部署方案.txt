AI Assistant 轻量化部署方案

一、部署环境要求

Python 3.8 或更高版本，内存不低于 4GB，磁盘空间不低于 20GB。操作系统推荐 Ubuntu 20.04 LTS 或 CentOS 7。需要 Docker 和 Docker Compose v1。

二、最小配置

CPU: 2 核心，内存: 4GB，磁盘: 20GB SSD。可支持单用户日常使用，建议文档库规模控制在 1000 份以内。API 响应时间约 2-5 秒。

三、推荐配置

CPU: 4 核心，内存: 8GB，磁盘: 50GB SSD。可支持 3-5 人小团队使用，文档库建议控制在 5000 份以内。API 响应时间约 1-3 秒。

四、兼容性说明

兼容 Docker Compose v1 格式。支持 Python 2.7 兼容模式运行部分旧版脚本。GPU 加速不在覆盖范围内，建议使用 CPU 版本的嵌入模型。
