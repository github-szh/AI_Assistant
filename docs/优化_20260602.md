## 1. HyDE 失败日志

**问题**：深度搜索触发后，HyDE LLM 调用失败时 `except Exception: return None` 吞掉异常，调用方也静默跳过，导致日志说"深度搜索"但实际什么都没发生，排查困难。

**修复**：

| 文件 | 改动 |
|:--|:--|
| `src/knowledge/query_engine.py:318` | `except` 加 `logger.warning`，带上异常信息 |
| `src/knowledge/query_engine.py:173` | 调用方检测到 `None` 时 `logger.warning`，说明降级 |

**效果**：
```
WARNING | HyDE generation failed: timeout, falling back to original query
WARNING | HyDE returned empty, deep search skipped — using original query results
```

## 2. Reranker 子进程启动/耗时日志

**问题**：Reranker 子进程 spawn 没计时，推理也没计时，首次查询慢的原因（模型加载 ~8-10s）完全不可见。

**修复**：

| 文件 | 改动 |
|:--|:--|
| `src/knowledge/reranker.py:54` | `_ensure_worker()` Popen 前后计时 |
| `src/knowledge/reranker.py:91` | `rerank()` 推理前后计时，包含首次冷启动等待 `readline()` |
| `src/knowledge/reranker.py:96` | 降级日志也带耗时 |

**效果**：
```
INFO  | Reranker worker started in 0.1s              ← spawn 很快
DEBUG | Reranker scored 23 candidates → 5 results in 8.45s  ← 首次：模型加载阻塞
DEBUG | Reranker scored 23 candidates → 5 results in 0.42s  ← 后续：纯推理
WARNING | Reranker worker failed after 0.2s: broken pipe, falling back to raw order
```

**问题**：查询只记录总耗时，无法分离向量搜索、BM25、SW 展开等各阶段耗时，性能优化无从下手。

**修复**：

| 文件 | 改动 |
|:--|:--|
| `src/knowledge/retrieval.py` | `_bm25_search()`、向量搜索、`_expand_to_parents()` 各加计时 DEBUG 日志 |
| `src/knowledge/query_engine.py:125-127,133-134,153-161,208-216` | Level 1、粗召回、HyDE、深度检索各打检查点，汇总到 INFO 日志 |

**效果**：

## 4. Reranker 子进程 warm-up

**问题**：Reranker 子进程惰性启动，首次深度搜索用户要等 ~10s 冷启动加载模型，后续用户才正常。

**修复**：

| 文件 | 改动 |
|:--|:--|
| `src/knowledge/reranker.py:117-126` | 新增 `warmup()` 方法，spawn 子进程 + 发 dummy 请求等待模型加载完成 |
| `src/api/main.py:28-32` | `lifespan` 启动时调用 `get_reranker().warmup()` |

**效果**：应用启动时（与 embedding 模型预热并列）加载 Reranker 模型，首次用户查询直接走热路径 ~0.4s。

**资源占用**：内存 ~4-5GB（FP16），CPU 推理瞬时高、空闲几乎为 0。

## 6. OCR 多页检测优化

**问题**：`guess_need_ocr()` 只检查 PDF 第一页的中文字符数。封面页（图片/标题）中文 <10 个 → 误判为扫描件 → 走 PaddleOCR（慢、结果差），但第 2 页起全是正文。

**修复**：

| 文件 | 改动 |
|:--|:--|
| `src/parsing/loader.py:119` | `pages_to_check = min(3, len(doc))`，循环检查前 3 页，任一命中 CJK ≥10 即判为原生 PDF |

**边界兼容**：单页 PDF 行为完全不变（`min(3,1)=1`），空 PDF 安全处理（循环不执行直接判 OCR）。
