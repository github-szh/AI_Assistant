# 开发流程文档

> 本文档记录 RAGAS 集成的推进流程、关键决策和问题修复记录。

---

## 一、总体流程

```text
Phase 1: 噪声文档注入
  -> 创建 13 份噪声文档(.txt)
  -> 注入到 data/documents/ 知识库
  -> 验证前端可检索到噪声文档

Phase 2: 发现评估盲区
  -> 测试发现模型引用了噪声文档
  -> 但质量评估全部给满分(100)
  -> 原因：FactualityChecker只检查"回答vs上下文"

Phase 3: RAGAS 集成
  -> 创建 ragas_checker.py (3个检查器)
  -> 修改 query_engine.py 挂载新检查器
  -> 配置 guard.py 和 intervention.py

Phase 4: 前端适配
  -> 添加 answer_correctness 中文标签
  -> 去掉 Pass/Fail 徽章
  -> 添加标准答案输入框
  -> 详情拆分为"可读描述+技术数据"两行

Phase 5: 问题修复
  -> 修复 answer_correctness 维度不执行的问题
  -> 修复 ground_truth 回退到 context 的问题
  -> 添加数值一致性检查(30 vs 20)
```

---

## 二、关键决策记录

### 决策 1：不安装 ragas 包，从零实现

| 项目 | 内容 |
|------|------|
| **背景** | pip install ragas 因依赖编译超时失败 |
| **决策** | 自实现 RAGAS 核心算法 |
| **原理** | F1(声明分解) + 语义相似度(embedding) + 加权融合 |
| **文件** | `src/quality/ragas_checker.py` |

### 决策 2：answer_correctness 作为独立维度而非合并

| 项目 | 内容 |
|------|------|
| **背景** | 事实性(faithfulness)只检查"回答vs上下文" |
| **决策** | 新增独立维度 answer_correctness，对比"回答vs标准答案" |
| **理由** | 两个维度语义不同，分开更清晰 |
| **效果** | 生产环境无标准答案时跳过，测评数据集时生效 |

### 决策 3：去掉 Pass/Fail 徽章

| 项目 | 内容 |
|------|------|
| **背景** | 分数 41 但显示 Pass，自相矛盾 |
| **决策** | 删除二元标签，仅保留分数和进度条 |
| **理由** | 分数本身是最直观的度量 |

### 决策 4：添加 ground_truth 参数传递

| 项目 | 内容 |
|------|------|
| **背景** | answer_correctness 需要标准答案但收不到 |
| **决策** | 从 QueryRequest -> query_engine -> guard -> checker 全线透传 |
| **改动** | schemas.py / query.py / guard.py 共三个文件 |

## 三、问题修复记录

### Bug 1：answer_correctness 不执行

| 项目 | 内容 |
|------|------|
| **现象** | 前端不显示 answer_correctness 维度 |
| **原因** | guard.py 的 _LLM_DIMENSIONS 列表中没有 answer_correctness |
| **修复** | 添加到列表中 |
| **同时修复** | intervention.py 的 _DIMENSION_TO_PREFIX 和 _DIMENSION_PRIORITY 也缺失 |

### Bug 2：无标准答案时显示"一致"

| 项目 | 内容 |
|------|------|
| **现象** | 没填标准答案但答案正确性显示"与标准答案一致" |
| **原因** | ground_truth = kwargs.get(..) or context，把检索文档当成了标准答案 |
| **修复** | 去掉 or context，无标准答案时返回 0.5/跳过 |

### Bug 3：top_k=30 被判定为"一致"

| 项目 | 内容 |
|------|------|
| **现象** | 回答 top_k=30，标准 top_k=20，仍显示一致 |
| **原因** | 语义相似度高(都说top_k)，jieba 关键词重叠高 |
| **修复** | 新增 _check_numeric_consistency() 数值一致性检查 |
| **原理** | 提取数字逐对比较，数值不匹配时降低 F1 |
