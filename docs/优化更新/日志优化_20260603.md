# 优化: LLM 调用日志 — 显示耗时 + Token 消耗

**日期**: 2026-06-03
**类型**: 可观测性增强

---

## 问题

LLM 调用成功时完全静默，以下信息不可见：

| 缺失 | 影响 |
|------|------|
| 调用耗时 | 无法判断慢查询是 LLM 还是检索导致 |
| Token 消耗 | 无法核算 API 费用（DeepSeek 按 token 计费） |
| 实际 provider | 配置了 fallback，但不知道哪次走了备选 |

已有日志只在**失败时**记录（retry/fallback warning），成功调用无日志。

## 方案

内部 provider 返回元数据（`ChatResult`），router 消费后对外仍返回 `str`。调用方完全无感。

### 数据结构

```python
@dataclass
class ChatResult:
    text: str
    usage: dict | None = None  # {"prompt_tokens", "completion_tokens", "total_tokens"}

@dataclass
class StreamChunk:
    text: str | None = None
    usage: dict | None = None  # 最后一个 chunk 携带
```

### 数据流

```
非 Stream:
  provider.chat() → ChatResult(text, usage)
    → router: 取 .text 返回（对外 str），取 .usage 记日志

Stream:
  provider.chat_stream() → yield StreamChunk(text/usage)
    → router: yield chunk.text（对外 str），收集 chunk.usage，循环结束记日志
```

## 改动文件（7 个，~50 行）

| 文件 | 改动 |
|------|------|
| `src/llm/base.py` | 新增 `ChatResult`, `StreamChunk`；`chat()` 返回类型 `str` → `ChatResult`；`chat_stream()` 返回类型 `Iterator[str]` → `Iterator[StreamChunk]` |
| `src/llm/providers/deepseek.py` | `DeepSeekProvider.chat()` 返回 `ChatResult`；`chat_stream()` yield `StreamChunk`；含 `DeepSeekProviderV4`；stream 加 `stream_options={"include_usage": True}` |
| `src/llm/providers/openai.py` | 同上 |
| `src/llm/providers/ali.py` | 同上 |
| `src/llm/providers/zhipu.py` | `chat()` 返回 `ChatResult`；`chat_stream()` yield `StreamChunk`（**不加** `stream_options`，zai SDK 不支持） |
| `src/llm/providers/mock.py` | `chat()` 返回 `ChatResult(text=...)`，无 usage |
| `src/llm/router.py` | `chat()` 内提取 `result.text` + `result.usage`，`logger.info` 记日志后返回 `result.text`；`chat_stream()` 内解包 `StreamChunk`，收集 usage，循环结束后记日志；新增 `_usage_str()` 格式化 |

### 不动文件（8 个调用方，零改动）

`query_engine.py`, `chat.py`, `chat_stream.py`, `summarizer.py`, `upload.py`, `ssl_utils.py` — 对外接口仍是 `-> str`。

## Stream usage 支持情况

| Provider | 非 Stream | Stream |
|----------|:---:|:---:|
| DeepSeek | ✅ | ✅ `stream_options={"include_usage": True}` |
| OpenAI | ✅ | ✅ 同上 |
| Ali | ✅ | ❓ 不确定（加 `stream_options` 尝试） |
| Zhipu | ✅ `hasattr` 保护 | ❌ zai SDK 不支持，stream usage 为 `?` |

# 优化: 补盲区日志 — Chunker + 静默异常

**日期**: 2026-06-03
**类型**: 可观测性增强

---

## 问题

3 个关键路径完全无日志：

| 位置 | 问题 | 影响 |
|------|------|------|
| `chunker.chunk()` | 文档切割是重操作，无日志 | 不知切了多少块、耗时多少、用什么策略 |
| `chunker.chunk_with_windows()` | 同上，Sentence Window 模式 | 不知子块/父块数量 |
| `index_store._search_summaries()` | 异常被裸 `except` 吞掉 | PG 故障时静默降级，无排查线索 |
| `index_store._fetch_parent_contexts()` | 同上 | 父块获取失败时静默返回空，检索质量下降无感知 |

## 改动文件（2 个，~8 行）

| 文件 | 改动 |
|------|------|
| `src/parsing/chunker.py` | 新增 `import logging`, `import time`, `logger`；`chunk()` 入口加 INFO（页数→块数，策略，耗时）；`chunk_with_windows()` 入口加 INFO（页数→子块数+父块数，策略，耗时） |
| `src/knowledge/index_store.py` | `_fetch_parent_contexts()` 裸 `except` → `except Exception as exc: logger.warning("父块获取失败: ...")`  ；`_search_summaries()` 裸 `except` → `except Exception as exc: logger.warning("摘要搜索失败: ..., 降级为全库搜索")` |

## 日志效果

```text

INFO | src.parsing.chunker | SW切割: 5页 → 23子块 + 8父块, 策略=sentence (0.18s)

# 异常情况
WARNING | src.knowledge.index_store | 父块获取失败: 18 IDs → connection timeout
WARNING | src.knowledge.index_store | 摘要搜索失败: connection refused, 降级为全库搜索
```

# 优化: 清扫剩余裸 except — 3 处

**日期**: 2026-06-03
**类型**: 可观测性增强

## 问题

全库 `except Exception:` 审计后发现 3 处静默吞错误：

| 文件 | 位置 | 问题 |
|------|------|------|
| `query_engine.py` | `_count_documents()` 返回 0 | PG 故障时文档数返回 0，两级检索被永久跳过，全部走全库搜索 |
| `loader.py` | `guess_need_ocr()` 返回 True | OCR 检测异常时默认走 OCR，扫描件可能被当原生 PDF 解析 |
| `documents.py` | `_get_chunks()` 返回 `[]` | PG 故障时前端文档页静默显示空内容 |

## 改动（3 个文件，3 行）

| 文件 | 改动 |
|------|------|
| `src/knowledge/query_engine.py` | `except Exception:` → `except Exception as exc: logger.warning("文档计数失败: %s, 默认 0（跳过两级检索）", exc)` |
| `src/parsing/loader.py` | `except Exception:` → `except Exception as exc: logger.warning("OCR检测失败，默认启用OCR: %s", exc)` |
| `src/api/routes/documents.py` | `except Exception:` → `except Exception as exc: logger.warning("获取文档片段失败: %s → %s", doc_id, exc)` |

## 日志效果

```text
WARNING | src.knowledge.query_engine | 文档计数失败: connection refused, 默认 0（跳过两级检索）
WARNING | src.parsing.loader | OCR检测失败，默认启用OCR: PyPDF2 not installed
WARNING | src.api.routes.documents | 获取文档片段失败: abc123 → connection timeout
```
